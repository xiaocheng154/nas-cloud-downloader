百度网盘首次配置

如何配置 BDUSS 和 STOKEN

这两个值属于登录凭据，只需在首次使用或凭据失效时重新获取。

  1. 登录网页版在电脑浏览器中登录百度网盘网页版。
  2. 打开开发者工具按 F12，进入 Network 面板后刷新页面。
  3. 找到 Cookie选择发往 pan.baidu.com 的请求，在 Request Headers 中查看 Cookie。
  4. 分别复制复制 BDUSS 和 STOKEN 的值，不要包含字段名、等号和分号。
  5. 验证并保存进入“设置 → 账号与凭据”，粘贴后点击“验证并保存”。
不要通过聊天、截图或公开渠道发送 BDUSS、STOKEN。凭据失效后请重新登录百度网盘获取。

完成后以后不再自动提示；获取方法仍可在“设置 → 账号与凭据”中查看。

百度网盘

未配置
如何获取百度凭据
  1. 在电脑浏览器登录百度网盘网页版。
  2. 按 F12 打开开发者工具，进入 Network，然后刷新页面。
  3. 选择发送到百度网盘域名的请求，在 Request Headers 中找到完整 Cookie。
  4. 复制完整 Cookie 并粘贴到上方输入框，应用会自动提取并只保存 BDUSS、STOKEN。

夸克网盘

未配置
如何获取夸克 Cookie
  1. 在电脑浏览器登录夸克网盘网页版 pan.quark.cn。
  2. 按 F12 打开开发者工具，进入 Network，然后刷新页面。
  3. 选择发送到 pan.quark.cn 或 drive-pc.quark.cn 的请求。
  4. 在 Request Headers 中复制完整 Cookie 值。
  5. 可以直接粘贴带 Cookie: 开头的内容，输入框会自动清理。

未配置
如何获取阿里云盘 refresh_token
  1. 用官方客户端或官方网页登录阿里云盘。
  2. 从浏览器 Local Storage / 客户端配置中复制 refresh_token。
  3. 直链可用性由阿里云盘服务决定；需要更稳定的大文件下载时建议使用 OpenAPI。
  4. refresh_token 属于登录凭据，请勿外泄。
开放平台 OAuth 模式
  1. 在 open.alipan.com 注册应用，获得 client_id 与 client_secret。
  2. 填入下方两个字段，并使用开放平台获取的 refresh_token。
  3. OpenAPI 支持大文件直链，并按“每文件连接数”设置进行分片下载。

Cookie、BDUSS、STOKEN 和 refresh_token 等同于登录凭据，请勿通过聊天、截图或公开渠道发送。若已经泄露，请立即退出账号会话并重新登录。
