# 夸克凭据验证与主题切换动效设计

## 目标

修复夸克 Cookie 验证时直接显示 `Expecting value: line 1 column 1 (char 0)` 的问题；为黑夜与白天主题切换增加从切换按钮向外扩散的圆形过渡；在“设置 > 账号与凭据”中加入百度网盘和夸克网盘凭据获取指引。

## 夸克 Cookie 验证

- 使用当前夸克网页端的账户接口验证 Cookie，不再使用失效的旧 `/api/user/info` 路径。
- 请求携带夸克网页端所需的公共查询参数与浏览器请求头。
- 在解析前检查 HTTP 状态、内容类型和响应正文。
- 空响应、HTML 风控页、非 JSON 响应、超时、网络失败和 Cookie 失效分别转换为清晰的中文提示。
- 验证失败时不保存新 Cookie，也不替换当前可用客户端。
- 日志只记录状态码、内容类型和经过截断的非敏感错误类型，不记录 Cookie 或响应中的敏感字段。
- Cookie 输入支持去除误复制的 `Cookie:` 前缀和首尾空白，但不改变 Cookie 名称和值。

## 主题切换过渡

- 动画从用户实际点击的主题按钮中心开始，以圆形遮罩向外扩散至覆盖整个视口。
- 动画时长约 450ms，使用平滑的非线性缓动。
- 优先使用浏览器 View Transitions API；不支持时退化为短暂的整体颜色过渡。
- 桌面与移动端分别使用各自按钮的点击坐标作为扩散原点。
- 主题仍按“跟随系统、浅色、深色”循环，已有本地主题偏好保持不变。
- `prefers-reduced-motion: reduce` 时立即切换，不播放扩散动画。
- 动画层不接收鼠标事件，不影响键盘焦点和屏幕阅读器。

## 凭据获取指引

“设置 > 账号与凭据”页面增加可展开的操作指引：

### 百度网盘

1. 在电脑浏览器登录百度网盘网页版。
2. 按 `F12` 打开开发者工具，进入 `Network/网络`。
3. 刷新页面并选择发送到百度网盘域名的请求。
4. 在 `Request Headers/请求标头` 中找到完整 Cookie。
5. 从 Cookie 中分别复制 `BDUSS` 和 `STOKEN` 的值。

### 夸克网盘

1. 在电脑浏览器登录 `https://pan.quark.cn`。
2. 按 `F12` 打开开发者工具，进入 `Network/网络`。
3. 刷新页面并选择发送到 `pan.quark.cn` 或 `drive-pc.quark.cn` 的请求。
4. 在 `Request Headers/请求标头` 中复制完整 Cookie 值。
5. 粘贴时不包含开头的 `Cookie:` 字样。

指引明确说明 Cookie、BDUSS 和 STOKEN 等同于登录凭据，不应通过聊天、截图或公开渠道发送；若已泄露，应退出对应账号会话并重新登录。

## 测试与验收

- 单元测试覆盖夸克成功 JSON、空正文、HTML 风控页、HTTP 401/403、无效 JSON与网络异常。
- API 测试确认验证失败不会保存 Cookie，成功后只返回配置状态而不回显凭据。
- 静态 UI 测试确认凭据指引、主题扩散逻辑和减少动态效果回退存在。
- 全量自动化测试通过后重新使用官方 `fnpack` 生成 x86_64 原生 FPK。
- 最终在 fnOS 1.1.3107 实机验证 Cookie 保存、主题切换、应用重启后的凭据持久化。
