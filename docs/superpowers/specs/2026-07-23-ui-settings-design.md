# CloudDownloader UI、设置与下载策略设计

## 目标

将现有单文件页面重构为与批准效果图一致的桌面级 Web UI，支持自动深浅主题、完整移动端适配和每浏览器会话一次的 3 秒启动动画。同时新增持久化设置、凭据管理、下载策略、日志与诊断，并重新生成可安装的 fnOS x86 FPK。

## 前端

- 桌面端 220px 左侧栏：Logo、百度网盘、夸克网盘、下载任务、设置。
- 中等窗口侧栏缩为 80px；手机端改为底部导航。
- 右侧内容区包含模块标题、账号状态、搜索、刷新、面包屑、文件表格或任务列表。
- 浅色主题以暖白、白色和石墨文字为主；深色主题保持相同结构，仅反转设计令牌。
- 唯一强调色为低饱和钴蓝。
- 前端拆为 `index.html`、`styles.css`、`api.js`、`app.js`。
- 不使用 React、Vue、外部字体、图标库或动画 CDN。

## Logo 与启动动画

- Logo 采用用户批准的深色云轮廓和蓝色向下箭头。
- 实现时重绘为边缘清晰、无渐变的 SVG，自动适配深浅主题。
- 动画约 3 秒：背景淡入、云形绘制、箭头下落、名称出现、Logo 缩入侧栏、内容区展开。
- 每个浏览器会话只播放一次，使用 `sessionStorage`。
- 提供“跳过”，并为 `prefers-reduced-motion` 用户降为约 0.3 秒淡入。

## 首次使用引导与免责声明

- 新安装首次进入时，在启动动画之后显示不可绕过的新手引导。
- 引导依次介绍应用用途、凭据安全、下载策略和风险边界。
- 最后展示完整免责声明；用户必须主动勾选“我已阅读并同意”才能进入主要功能。
- 后端保存 `disclaimer_version` 与 `accepted_at`，不能仅依赖浏览器本地状态。
- 未接受当前版本时，文件浏览、下载、设置、日志和诊断业务接口返回 `403`；引导状态和接受接口保持可用。
- 免责声明版本升级后再次要求确认。
- 免责声明明确说明非官方网盘接口、Cookie 风险、账号限制、服务变化、用户数据与合法使用责任。

## 设置

设置保存到挂载为 `/config` 的持久化应用配置目录，普通设置和敏感凭据分文件保存，均使用临时文件加原子替换。

默认设置：

```json
{
  "duplicate_policy": "error",
  "reserve_space_gb": 50,
  "total_speed_limit_mbps": 0,
  "connections_per_file": 3,
  "segment_size_mb": 5,
  "max_segment_requests": 30,
  "schedule_enabled": false,
  "schedule_start": "00:00",
  "schedule_end": "00:00",
  "concurrent_downloads": 3,
  "log_level": "INFO",
  "log_retention_days": 7,
  "log_max_size_mb": 10
}
```

同名策略包含：

- `error`：默认。只有远端提供可靠哈希且与本地文件匹配时直接完成；否则保留本地文件并将任务标为失败。
- `rename`：自动生成不冲突的新文件名。
- `overwrite`：下载到临时文件，成功后原子替换本地文件。
- `skip`：保留本地文件，并将任务标为已跳过。

下载时段支持跨午夜；开始与结束相同表示全天。设置保存后立即影响新任务；并发数、总限速和下载时段无需重启。

## 凭据

- 百度保存 BDUSS、STOKEN；夸克保存 Cookie。
- 前端只能读取是否已配置及脱敏账号，不能重新读取凭据原文。
- 支持覆盖、清除和登录验证。
- 诊断包永久排除凭据。

## 下载调度

- 默认同时下载 3 个任务。
- 单文件默认 3 个 Range 连接，每片 5MB。
- 所有任务合计最多 30 条分片请求。
- 总下载限速由所有并发任务共享，0 表示不限速。
- 可用空间低于“任务剩余大小 + 50GB 保留空间”时暂停，恢复满足条件后继续。
- 任务状态包含排队、等待时段、下载中、磁盘暂停、完成、跳过、失败、取消。

## 日志与诊断

- 支持 ERROR、WARNING、INFO、DEBUG 日志级别。
- 支持日志轮转、查看尾部、下载、清空。
- 一键诊断配置目录、下载目录、剩余空间、Range 下载能力和网络连通性。
- 导出 ZIP 诊断包，包含版本、运行时间、脱敏设置、诊断结果和日志。
- 不包含 Cookie、BDUSS、STOKEN 或下载 URL。

## 错误处理

- 前端与后端双重校验设置字段。
- 保存失败不覆盖旧配置。
- API 返回稳定的错误信息，前端使用统一提示和错误状态。
- 危险操作需要确认。
- 下载失败保留可诊断错误，不删除已有同名文件。

## 测试与验收

- 单元测试覆盖配置默认值、校验、原子保存、凭据脱敏、时段判断、重名策略、磁盘保护和日志脱敏。
- API 测试覆盖设置读取保存、凭据覆盖清除、日志和诊断。
- API 测试覆盖未接受免责声明时的业务接口拦截、版本记录和重新确认。
- 浏览器测试覆盖导航、主题、响应式、设置保存、首次引导、强制免责声明和启动动画会话行为。
- 1600×1000 浅色桌面截图对齐批准效果图；动态文字和真实数据允许不同。
- FPK 测试继续验证根目录、Linux 权限、LF 换行和 JSON 元数据。
