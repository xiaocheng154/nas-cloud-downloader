# BT 下载与五秒启动动画设计

## 范围

本次增加磁力链接和 `.torrent` 种子文件下载，并将任务统一放入“下载任务”页面；启动动画的完整播放时长由 3 秒调整为 5 秒。迅雷接入不在本次范围内。

## 原生 BT 引擎

- 在 x86_64 fnOS 安装包中内置经过校验的 Linux x86_64 `aria2c`，不依赖 Docker，也不要求系统预装 aria2。
- 应用服务启动时以子进程方式启动 aria2，RPC 只监听 `127.0.0.1`，并使用每次安装生成的随机密钥。
- aria2 的会话文件、DHT 状态、任务元数据和上传的种子文件保存在应用配置目录；实际下载内容仍写入用户在安装时选择的下载目录。
- 应用停止时先保存会话并正常结束 aria2；异常退出后再次启动能够恢复未完成任务。
- BT 默认开启 DHT、PEX 和本地节点发现，不内置来源不明的公共 Tracker 列表。

## 新建下载任务

“下载任务”页面右上角增加“新建任务”按钮，打开简洁的任务面板：

- “磁力链接”页签：粘贴一个合法的 `magnet:?xt=urn:btih:...` 链接。
- “种子文件”页签：选择并上传一个 `.torrent` 文件。
- 种子文件限制为单文件、扩展名 `.torrent`、最大 10 MB；服务端还会检查文件结构，不能只依赖扩展名。
- 创建成功后立即关闭面板并在任务列表中显示。磁力任务在取得元数据前显示“正在获取元数据”，取得后显示真实名称和总大小。
- 本期默认下载种子内全部文件，不加入逐文件选择器。

## 统一任务模型

现有 HTTP/网盘下载与 BT 下载继续使用各自引擎，但通过统一任务适配层输出：

- 任务类型：百度、夸克、磁力、种子。
- 公共字段：任务 ID、名称、总大小、已下载、进度、实时速度、状态、错误、创建时间。
- BT 扩展字段：连接节点数、上传速度、分享率和元数据状态。
- 公共操作：暂停、继续、取消、删除记录。
- 取消未完成任务时先停止传输；是否删除已下载数据必须再次确认，默认保留数据。
- 应用重启后 BT 任务由 aria2 会话恢复；现有 HTTP 任务行为保持不变。

## 下载策略联动

- 下载并发数、指定时段、磁盘保留空间和总下载限速同时作用于 BT 任务。
- 可用空间低于“任务剩余大小 + 磁盘保留空间”时暂停 BT 任务，空间恢复后继续。
- 全局限速为 `0` 时应用不主动限制 BT 下载速度，但实际速度仍取决于资源节点、网络和设备性能。
- BT 下载路径必须处于安装时选择的下载目录内，拒绝通过种子文件中的路径穿越写入其他位置。
- 同名根目录按现有同名文件策略处理；不会静默覆盖已有本地文件。

## 做种设置

“设置 > 下载策略”增加：

- “下载完成后继续做种”开关，默认关闭。
- 开启后显示“停止分享率”，默认 `1.0`，允许范围 `0.1–10.0`。
- 默认关闭时，任务下载完成后立即停止上传并进入“已完成”状态。
- 开启时，下载完成后进入“做种中”，达到目标分享率后自动停止并进入“已完成”。
- 用户可随时手动停止做种，不影响已经下载的文件。

## 启动动画

- 首次打开当前浏览器会话时，启动动画总播放时长调整为 5 秒。
- 动画内部节奏同步拉长，云轮廓、下载箭头、应用名称和说明文字分阶段完成，不用静止画面补足时长。
- 保留右上角“跳过动画”，点击后立即进入应用。
- 同一浏览器会话再次打开时继续跳过完整动画。
- 系统启用“减少动态效果”时不播放五秒动画，直接进入应用。
- 新手引导仍在启动动画结束或跳过后出现，不与启动层重叠。

## 错误处理与安全

- aria2 无法启动、RPC 不可连接、磁力格式错误、种子损坏、元数据超时、磁盘不足和无可用节点均显示明确中文提示。
- 日志不记录完整磁力链接；只记录截断后的任务哈希。种子原始内容不写入日志或诊断包。
- 只允许用户下载其有权获取和传播的内容，界面在新建 BT 任务处显示简短版权与合规提示。
- Web API 对种子上传大小和请求体进行限制，文件名由服务端重新生成，不能由用户输入控制保存路径。

## 测试与验收

- 单元测试覆盖磁力格式校验、种子上传限制、路径穿越防护、统一状态映射、做种开关和分享率校验。
- API 测试覆盖创建、暂停、继续、取消、删除、任务恢复与错误响应。
- 使用隔离的假 RPC 服务测试控制逻辑，不在自动化测试中连接公共 BT 网络。
- 静态 UI 测试确认新建任务面板、两种输入方式、做种设置和五秒动画逻辑。
- 重新执行全部现有测试，使用官方 `fnpack` 生成原生 x86_64 FPK，并检查包内 `aria2c` 为 Linux x86_64 ELF。
- 最终在 fnOS 1.1.3107 实机验证 aria2 启动、磁力元数据、种子下载、重启恢复、磁盘保护和五秒启动动画。
